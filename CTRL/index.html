Getting started with Prosperity 5

IMC has not published Prosperity 5 dates or rules yet (last checked 15 November 2026). These six steps carry over from earlier editions. The two marked “waiting for P5 docs” change once the new wiki is live.

  1. Read the official rules and wikiwaiting for P5 docs

    Each edition publishes a wiki with the products, position limits, round schedule and submission format. Treat it as the source of truth; this guide fills in context around it.

    Open prosperity.imc.com ↗

  2. Set up Python and a research notebookready now

    Any editor works: VS Code, PyCharm or Jupyter. Earlier editions took a single Python file and allowed only a short list of libraries, so keep the trader itself light and do the heavy research in a notebook.

    Use the Library's research workbench for loaders, features and a first backtest.

  3. Learn the trader interfaceready now

    From Prosperity 2 onwards the platform called Trader.run(state) once per timestep. You read the order book, your position and recent trades, then return your orders, a conversion request and a string that comes back to you on the next call.

    Editions add to it: Prosperity 4's second round used an extra bid() method for a one-off auction. The skeleton beside this list is a starting point, not a specification.

  4. Load the historical dataready now

    Four editions of prices, trades and observations, profiled file by file: products, days, row counts, duplicates and the files that are not what their name says.

    Open the historical data terminal

  5. Backtest locally, then on the platformready now

    Community backtesters replay the historical files against your trader. Their fill assumptions differ from the platform's, so local and platform results rarely match. Use the backtester as a fast filter and the platform as the benchmark.

    Jasper van Merle's Prosperity 3 backtester ↗ and a Prosperity 4 port of it ↗

  6. Compare every new round with the archivewaiting for P5 docs

    New products, mechanics and limits arrive round by round. On day one, check the new data against the old: earlier editions reused product designs, price paths and in one case an entire order book.

    Read the known alphas and study 001.

A quick orientation

What is IMC Prosperity?

IMC Prosperity is a simulated trading competition combining algorithmic and manual challenges. Teams investigate the market, make decisions and learn from the results across a series of rounds.

trader.py → exchange

Algorithmic challenges

Develop a Python trading program that responds to market information. Research, order behaviour and position management all matter.

one decision → platform

Manual challenges

Reason through a separate trading problem and submit decisions through the competition platform.

results → next round

Learn between rounds

Review the results, investigate new information and refine the approach. The exact mechanics belong to each edition.
