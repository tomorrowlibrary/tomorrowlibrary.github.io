1 · Understand the contract

Read the organiser's rules, interface, scoring, position limits, runtime limits and eligibility requirements. Confirm which observations are available at each decision. A high-scoring idea is irrelevant if it produces invalid orders or depends on information the interface does not supply.

2 · Get a valid baseline running

Build the smallest valid submission and run it through the official examples. Log inputs, decisions, inventory and PnL. Preserve the last known working version before adding strategy logic.

3 · Study the market design

Inspect prices, spreads, depth, trades, product relationships and any conversion mechanics. Form a specific hypothesis for each product. A fixed-value product, a basket and an option may require different models. Historical patterns from earlier editions are starting questions, not future answers.

4 · Split the team by responsibility

Assign research, execution/risk and engineering responsibilities. Use a shared experiment log and an agreed order interface. Test combined inventory and exposure: individually sensible components can conflict when they trade together.

5 · Compare with discipline

Use the same data windows and execution assumptions. Keep the parameters tried, analyse per-product contributions and inspect adverse cases. Use edition-compatible backtesting tools; midpoint return studies and interactive simulations answer narrower questions.

6 · Protect the submission

7 · Write the post-mortem

Keep the submitted code, round-specific data, configurations and official result. Explain each hypothesis, what the local tests predicted and what the official evaluation showed. Distinguish your actual submission from later improvements.

Study solutions actively

The solutions collection separates Tomorrow's guides and analyses from external winning and public submissions. For each solution, identify the market mechanism, available information, execution assumptions and validation weaknesses. Reimplement one component before comparing with the original code.
